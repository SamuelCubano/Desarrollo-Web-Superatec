public/ ← Carpeta mágica
index.html → se sirve en /
style.css → se sirve en /style.css
script.js → se sirve en /script.js
💻 Solo 3 líneas mágicas 
const express = require('express');
const app = express();
const puerto = 3000;

// 👇 Esta línea hace TODO el trabajo
app.use(express.static('public'));

app.listen(puerto, () => {
  console.log(`Server en http://localhost:${puerto}`);
});
🧠 Reglas de oro
1

No pongas public en la URL

El navegador pide /style.css, Express busca en public/style.css

2

index.html es especial

Se sirve automáticamente en la raíz / sin escribir el nombre

3

El orden importa

Pon express.static antes de tus rutas API para que no las intercepte

4

Múltiples carpetas

app.use(express.static('public')) y app.use('/assets', express.static('assets'))
